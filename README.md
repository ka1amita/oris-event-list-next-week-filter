# ORIS next week filter shortcut

A tiny static page that redirects to the [ORIS](https://oris.ceskyorientak.cz/) event list with the date range filled in for you. Add it to your smartphone and one tap shows the races you care about, with no manual date picking.

Hosted on GitHub Pages.

## Adding to the iPhone Home Screen

Because the page redirects immediately, Safari is already on ORIS by the time you tap Share. Workaround:

1. iPhone Settings → Apps → Safari → Advanced → turn **JavaScript** off.
2. Open the page URL in Safari. It no longer redirects.
3. Share → **Add to Home Screen**.
4. Turn **JavaScript** back on.
